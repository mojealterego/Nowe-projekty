# PRD — Customer Operations Agent

## MVP
- omnichannel intake;
- customer identity/context lookup;
- knowledge retrieval with source citations;
- ticket classification;
- calendar/CRM/helpdesk actions;
- approval rules;
- escalation and human handoff;
- outcome analytics.

## KPIs
First-contact resolution; median time to resolution; action success rate; escalation precision; customer recontact rate.

## Safety
Never invent account state. If required data is unavailable, state the limitation and escalate. Destructive, financial and irreversible actions require explicit authorization.
