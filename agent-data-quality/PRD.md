# PRD — Data Quality Agent

## MVP
- connector-based profiling;
- schema and business-rule validators;
- duplicate detection;
- anomaly detection;
- explainable issue cards;
- patch proposals;
- policy-based auto-fix;
- post-fix verification and audit.

## Principle
Deterministic checks decide whether data is invalid; the LLM explains, prioritizes and proposes transformations. It does not invent canonical values without evidence.

## KPIs
Issue precision >97%; auto-fix rollback <1%; mean time to resolution -70%; recurring issue rate month-over-month decline.
