# PRD — Inventory Replenishment Agent

## MVP
- stock/sales connector;
- SKU-level demand baseline;
- lead-time model;
- safety-stock calculation;
- reorder proposal;
- supplier comparison;
- approval gate;
- purchase/order status tracking.

## Safety
No purchase commitment without policy-approved threshold or explicit human approval. Handle stockouts and negative inventory as high-priority exceptions.

## KPIs
Stockout reduction; inventory carrying cost; forecast error; purchase-order cycle time; proposal acceptance rate.
