# PRD — AI FinOps Agent

## MVP
- model/provider usage ingestion;
- workflow cost attribution;
- budgets and thresholds;
- spend anomaly detection;
- monthly forecast;
- model/routing optimization proposals;
- policy-controlled automatic routing;
- savings ledger.

## Guardrails
Never switch to a cheaper model when policy requires a specific model, data residency, quality tier or tool capability. Every optimization records expected and realized savings.

## KPIs
Forecast MAPE; realized savings; cost per successful workflow; budget overrun rate; optimization rollback rate.
