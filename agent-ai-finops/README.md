# Agent AI FinOps

## Agent #9 — AI FinOps Agent

Agent zarządzający ekonomią pracy agentów: przypisuje koszty do agentów, workflow i klientów, wykrywa anomalie, prognozuje rachunek i proponuje tańsze ścieżki wykonania bez naruszania wymagań jakościowych.

### Workflow
Usage ingestion → attribution → budget state → anomaly detection → forecast → optimization proposal → policy decision → report.

### Architecture
TypeScript, Postgres/ClickHouse, provider billing adapters, token/cost telemetry, policy engine, alerting API.

### Monetization
€49/month base + 2% monitored AI spend, with enterprise annual contracts.

### Differentiator
Optymalizuje koszt na poziomie konkretnego zadania/workflow, a nie tylko rachunku dostawcy.
