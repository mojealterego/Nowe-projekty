## Arrow Heist production thesis

The project should not compete on content volume with major publishers. Its edge is a cheap-to-produce deterministic puzzle loop with a strong visual hook, quick sessions and expandable heist meta.

### Core loop

1. Read the board.
2. Route the arrow sequence.
3. Avoid security.
4. Secure loot.
5. Spend loot on progression.
6. Unlock new rule combinations.
7. Return for daily/event challenges.

### Monetization

- rewarded ads for second chance / bonus loot
- IAP starter bundles
- premium currency
- event passes
- cosmetics
- limited-time heist events

### Production gates

- prototype fun test
- D1/D7 retention gate
- tutorial completion
- level completion rate
- ad engagement
- payer conversion
- ARPDAU
- cohort LTV
- paid UA test

No large content expansion before retention and unit economics clear the gate.

## Portfolio rule

The goal is not to make the most complex game. The goal is to find the lowest-cost game loop capable of generating repeatable attention, retention and monetization.
