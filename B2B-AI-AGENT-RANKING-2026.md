## Selection rule

The best B2B agent is not the agent that can perform the most tasks. It is the agent that can own a measurable business outcome with clear authorization boundaries.

### Priority signals

- direct financial impact
- repetitive workflow
- multiple systems
- high labor cost
- low tolerance for error
- existing software budget
- outcome measurable inside 30–90 days
- path from human-in-the-loop to controlled automation

- identity and tenant isolation
- tool registry
- policy engine
- approval gates
- durable task state
- audit trail
- deterministic validators
- human escalation
- billing / usage metering
- outcome telemetry
