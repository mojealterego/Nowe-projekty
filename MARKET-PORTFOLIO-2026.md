### Architektura docelowa

```text
Android OS
   ↓
AppFunctions / platform APIs
   ↓
Agent Runtime
   ├─ Memory
   ├─ Tools
   ├─ Permissions
   ├─ Policy Engine
   └─ Audit Trail
   ↓
Reasoning Engine
   ├─ on-device model
   └─ cloud model
   ↓
Action Planner
   ↓
Human Approval Gate
   ↓
Action
   ↓
Verification
```

Autonomia:

- L0 — read only
- L1 — recommend
- L2 — prepare
- L3 — execute low-risk
- L4 — execute with confirmation
- L5 — autonomous only dla uprzednio zatwierdzonych, niskiego ryzyka scenariuszy

Android rozwija kierunek, w którym aplikacje mogą wystawiać funkcje agentom jako narzędzia, a system przechodzi od otwierania aplikacji do wykonywania zadań. To zwiększa wartość agentów wykonawczych względem zwykłych chatbotów.
